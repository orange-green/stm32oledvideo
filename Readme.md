基于STM32F103C8T6 + 0.96 寸 I2C OLED的视频播放项目。

## 功能说明

- 硬件：STM32F103C8T6 + 0.96" I2C OLED（SSD1306）
- 上位脚本：Python 脚本将视频拆分为 OLED 适配的位图帧数据
- 数据链路：Python 通过串口发送帧数据给 STM32
- 接收缓存：STM32 使用**环形缓冲区（ring buffer）**接收串口数据流，防止丢包
- 自定义简易通信协议：帧头、长度、校验，保障数据完整性，区分正常帧和干扰乱码
- 渲染：STM32 解析合法帧，刷新 OLED 屏幕实现视频播放

##  硬件资源

- 主控：STM32F103C8T6
- 屏幕：0.96 寸 I2C OLED SSD1306（128×64）
- 通信：USART 串口（和 Python 上位脚本通信）
- 协议：自研简易帧协议，带校验，保证数据可靠


## 使用流程

1. 使用 Python 脚本，把视频转换成适配 128×64 OLED 的二值位图帧
2. Python 脚本通过串口，按自定义协议打包发送每一帧数据
3. STM32 串口中断接收数据，存入环形缓冲区
4. 协议解析模块从环形缓冲取出字节，识别帧头、校验、长度
5. 校验通过后，把帧数据送到 OLED 进行刷新显示

## 注意事项

1. OLED 为 I2C 接口，注意接线、上拉，确认 I2C 地址
2. 串口波特率上下机必须一致
3. 环形缓冲区大小需要根据帧率、波特率合理配置，避免溢出丢帧
4. 自定义协议简单轻量，适合本项目，不适合复杂工业场景
